# skills

Claude Code 用の Skill 集。

## Skills

| Skill | 概要 |
|---|---|
| [requirements-review](skills/requirements-review/SKILL.md) | NASA Systems Engineering Handbook Appendix C のチェックリストで要件定義をレビューし、要件ごとの合否・理由・書き換え案と文書全体の指摘を出す（日本語・英語対応） |

## 使い方

使いたい Skill のディレクトリを `~/.claude/skills/`（個人用）または `<プロジェクト>/.claude/skills/`（プロジェクト用）にコピーする。

```sh
cp -r skills/requirements-review ~/.claude/skills/
```
