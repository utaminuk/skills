# 勤怠管理システム 要件定義（サンプル）

レビューの動作確認用のサンプル。意図的に問題を含めている。

1. システムは、社員がブラウザから出勤・退勤を打刻できること。
2. 打刻データは高速に保存され、管理者は適宜これを確認できること。
3. システムは PostgreSQL を使って打刻データを保存すること。
4. 管理者は毎月末に勤怠データを締め、給与システムへ CSV を送ること。
5. システムは使いやすい画面を提供すること。
6. システムは 99.9% の可用性を持つことが望ましい。
7. 打刻の際に二重打刻をしてはならない。
8. システムは、勤怠データを TBD 年間保存すること。
