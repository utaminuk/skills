# 日本語・英語の用語対応と語のリスト

NASA Appendix C は英語の要件文を前提にしている。日本語の要件文に当てはめるための対応表と、
曖昧語・検証できない語のリストをまとめる。英語の語は NASA の原文にあるもの、日本語の語は
それに対応する、または日本語の要件定義でよく見られるものを加えたもの。

語の一致だけで NG にしない。数値や基準と一緒に定義されていれば問題ない場合がある（SKILL.md の手順 3 を参照）。

---

## 1. C.1 の対応表（shall / will / should）

| NASA | 意味 | 日本語でよく使われる表現 | 判定 |
|---|---|---|---|
| shall | 要件（義務） | 「〜すること」「〜しなければならない」「〜するものとする」「〜できること」 | 要件として扱う |
| will | 事実・目的の宣言 | 「〜する」「〜である」「〜となる」（言い切りの平叙文） | 事実・説明として扱う。義務の意味で使われていれば、shall 相当の表現に直すよう指摘する（C1-02） |
| should | 目標 | 「〜が望ましい」「〜することが望ましい」「できるだけ〜する」「〜を目指す」「〜を目標とする」 | 目標として扱う。要件として扱いたいなら shall 相当の表現にするよう指摘する（C1-03） |

### 注意が必要な表現

| 表現 | 扱い |
|---|---|
| 「〜する」（言い切り） | 日本語の仕様書では要件の意味で使われることが多い。文書全体で要件を「〜する」で統一しているなら要件として扱い、C1 では文書全体の指摘として「shall 相当の表現への統一」を 1 回だけ提案する。文書内で「〜すること」と混在しているなら、どちらの意味かが曖昧なので個別に指摘する |
| 「〜できる」 | 「ユーザーが〜できる」は能力の説明か要件かが曖昧。「システムは、ユーザーが〜できる機能を提供すること」のように、主語を製品にした要件に直すよう提案する（C2-P-01） |
| 「〜とする」「〜ものとする」 | shall 相当。ただし定義文（「本書では X を Y とする」）なら要件ではない |
| 「〜してはならない」「〜しないこと」 | shall not 相当。C3-04 で肯定形にできないか検討する |
| 「〜も可」「〜してもよい」 | may 相当。NASA の C.1 にはない。要件ではなく許可・選択肢なので、要件一覧に入っていれば位置付けを確認するよう指摘する |
| must / is required to / needs to（英語） | 文書のスタイル規則で認められていなければ shall に統一するよう指摘する |

## 2. 曖昧語（C4-CL-01）

### 英語（NASA の原文にあるもの）
- as appropriate
- etc.
- and/or
- but not limited to
- 指示代名詞: this, these, that, those, it（何を指すか文中で明確でない場合）

### 日本語
- 「適宜」「適切に」「必要に応じて」「場合によっては」
- 「等」「など」「〜ほか」「その他」
- 「および／または」「および/または」「AまたはB」（両方か片方かが不明な場合）
- 「〜を含むがこれに限らない」「〜を含む」（範囲が閉じていない場合）
- 指示語: 「これ」「それ」「これら」「それら」「当該」「上記」「前述の」（何を指すか文中で明確でない場合）
- 主語の省略: 日本語は主語を省略しやすい。誰が・何が行うのかが書かれていなければ C2-P-01 / C2-PR-01 と併せて指摘する

## 3. 検証できない語（C4-VE-03）

### 英語（NASA の原文にあるもの）
flexible, easy, sufficient, safe, ad hoc, adequate, accommodate, user-friendly, usable,
when required, if required, appropriate, fast, portable, light-weight, small, large,
maximize, minimize, robust, quickly, easily, clearly, other "ly" words, other "ize" words

### 日本語
| 英語 | 日本語の例 |
|---|---|
| flexible | 柔軟な、柔軟に |
| easy, easily | 容易な、容易に、簡単に、手軽に、すぐに |
| sufficient, adequate | 十分な、十分に、相応の、妥当な |
| safe | 安全な、安全に、セキュアな（基準や規格が示されていない場合） |
| ad hoc | 臨機応変に、その都度 |
| accommodate | 対応できる、考慮する、配慮する |
| user-friendly, usable | 使いやすい、わかりやすい、直感的な、見やすい |
| when required, if required | 必要なときに、必要に応じて、要求があれば |
| appropriate | 適切な、適当な、適正な |
| fast, quickly | 高速な、高速に、迅速に、素早く、速やかに、リアルタイムに（時間の基準がない場合） |
| portable | 移植性の高い、可搬性のある |
| light-weight, small, large | 軽量な、小さい、大きい、コンパクトな、大量の、多数の |
| maximize, minimize | 最大化する、最小化する、できるだけ多く、できるだけ少なく、極力 |
| robust | 堅牢な、頑健な、安定した |
| clearly | 明確に、はっきりと |
| other "ly" words | 「〜的に」（効率的に、効果的に、自動的に*など）、「〜く」（正しく、美しくなど）の副詞 |
| other "ize" words | 「〜化する」（最適化する、効率化する、高度化するなど） |
| （日本語でよく見られるもの） | 高い／低い（性能が高い、可用性が高いなど）、十分な性能、快適な、スムーズな、シームレスな、柔軟に拡張できる、将来の拡張に備える、最新の、一般的な、標準的な |

\* 「自動的に」は「人の操作なしに」という意味で検証できる場合がある。文脈で判断する。

### 書き換えの方向
- 測定できる量（時間、件数、割合、サイズ、回数）と許容範囲に置き換える
  - 例: 「高速に検索できること」→「システムは、検索要求の 95% に対して 2 秒以内に結果を返すこと」
- 準拠する規格・基準に置き換える
  - 例: 「安全であること」→「システムは、<規格名> の <レベル> を満たすこと」
- 値が決まっていなければ数値を作らず、`[TBR: 値を決める]` とする（C3-05）
